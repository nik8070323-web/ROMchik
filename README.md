# РОМчик

**Репозиторий Образовательных Материалов** — Telegram-бот для удобного доступа к учебным материалам. Он помогает студентам находить и скачивать лекции по ОИТ и МДК, учебник по иностранному языку, а также титульный лист и регламент для реферата прямо в Telegram.

Бот написан на Python с использованием aiogram 3. Команда `/start` открывает приветствие и меню, `/help` показывает список команд.

## Запуск

Из корневой папки репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp aiogram-learning/.env.example aiogram-learning/.env
```

В `aiogram-learning/.env` укажите токен своего бота, полученный у @BotFather:

```dotenv
BOT_TOKEN=your_bot_token_here
ADMIN_IDS=
```

Для доступа к `/admin` укажите в `ADMIN_IDS` Telegram ID администраторов через запятую. Если список пуст, доступ закрыт для всех.

Запустите бота:

```bash
python aiogram-learning/main.py
```

Файл `.env`, виртуальные окружения, кеши Python и резервные копии исключены из Git через `.gitignore`. Не публикуйте настоящий токен бота.

Изображение приветствия находится в `images/welcome.png`, обработчики — в `aiogram-learning/handlers`, клавиатуры — в `aiogram-learning/keyboards`, учебные материалы — в `aiogram-learning/лекции`.

## Админ-панель

`/admin` открывает меню только для Telegram ID из `ADMIN_IDS`. Изменения списка
администраторов в `.env` применяются после перезапуска единственного экземпляра бота.

- **Добавить материал:** предмет → лекция/практика → номер 1–999999 → PDF/DOCX → подтверждение.
  После номера можно ввести название или нажать «Пропустить»: «Лекция № 1 — Введение» либо «Лекция № 1».
  В списке разделов доступно «Дополнительно» для лекций и практик; файлы сразу появляются в этом разделе.
  При занятом номере бот отдельно предупреждает о замене; до подтверждения файлы не меняются.
- **Управление материалами:** предмет → файл → замена или удаление с подтверждением.
  Старый учебник ИНО без номера также можно заменить или удалить через это меню.
- **Статистика:** реальные количества лекций, практик и файлов по предметам.
  Общее количество включает PDF/DOCX из папки `дополнительно`; резервные копии не учитываются.
- `/cancel`, «Отмена», выход в главное меню и `/start` очищают текущую загрузку.

Лимит загрузки — 20 МБ. Проверяются расширение, размер и базовый формат содержимого
(PDF-заголовок или структура DOCX). Это не полная проверка корректности документа.
Файл скачивается только после подтверждения; при ошибке бот предлагает повторную отправку.

Старые файлы остаются на месте. Новые лекции сохраняются в
`aiogram-learning/лекции/<папка предмета>/lecture_<номер>.pdf` (или `.docx`),
практики — в подпапке `практики/practice_<номер>.pdf` (или `.docx`).
Необязательное название добавляется к имени файла после « — ».
Имена загруженных документов не используются как пути сохранения.
Каталог читает папки при каждом запросе, поэтому перезапуск после загрузки не нужен.
Существующие имена `МДК_1.pdf` и `OIT_Lektsia_1.pdf` распознаются как лекция № 1.
Файлы без порядкового номера сохраняют старое отображаемое название.

Работа с файлами сосредоточена в `services/materials.py`, отдельно от Telegram-обработчиков,
чтобы позднее можно было подключить базу данных. FSM хранится в памяти:
после перезапуска незавершённую загрузку нужно начать заново. Запускайте один процесс бота.
Подтверждения привязаны к текущей операции и версии файла, изменённый другим администратором
материал требует нового подтверждения. При аварийном завершении процесса во время смены
расширения в папке может остаться скрытый `.upload-*.backup`; его следует проверить вручную.

### Проверка

```bash
python -m unittest discover -s tests -v
```

Тесты используют временные папки и подменяют Telegram API, не запускают polling
и не изменяют настоящие учебные материалы.

Для ручной проверки запустите бота командой выше, откройте `/admin`, добавьте материал
со свободным номером и проверьте его в «Учебные материалы». Затем проверьте замену,
отмену и подтверждённое удаление тестового материала. С аккаунта вне `ADMIN_IDS`
команда `/admin` должна возвращать отказ.
